Public-source interactive HTML preview for executive discussion. No credentials, internal commercial information, non-public merger dates, transaction lists, account data, or employer confidential materials.

## Relationship to existing work
This is a **standalone, reduced presentation layer**, not a replacement for the user's Canada Life master research, the private `fund-merger-timeline-tool` project, or the earlier Mackenzie merger workback. ## Architecture
One self-contained `index.html` with native HTML/CSS/JS. No frameworks, external scripts, analytics, cookies, uploads, external APIs or data storage. Horizontal scroll for the timeline on small screens; responsive one-column reading panels, keyboard-accessible buttons, and clear external primary-source hyperlinks.
